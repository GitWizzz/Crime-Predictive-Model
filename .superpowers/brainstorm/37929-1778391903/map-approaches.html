3 ways to fix the maps

All three fix tiles + real Bihar shapes + better visuals. They differ in how deep the overhaul goes.

A

Fix Leaflet in place Recommended

Keep react-leaflet. Switch to a reliable tile provider (OpenStreetMap / Stadia). Bundle real Bihar district GeoJSON as a static file in /public so the map never depends on the backend for shapes. Add crime intensity labels, proper legend, and color scale.

✅ Least code change
✅ Works with existing data
✅ Fastest to ship
⚠ Still Leaflet limits
⚠ Tiles need internet
What you'll see: Real Bihar map with 38 district shapes coloured by FIR density (blue → orange → red). Hotspot circles with crime count labels. Risk legend bottom-left. Tabs for Cluster / Heatmap / Women safety.
B

Upgrade to Mapbox GL

Replace react-leaflet with react-map-gl (Mapbox). Much smoother rendering, built-in satellite/street toggle, hardware-accelerated. Mapbox free tier = 50,000 map loads/month.

✅ Best visual quality
✅ Smooth zoom/pan
✅ 3D terrain option
❌ Needs Mapbox API key
❌ Larger rewrite
❌ External dependency
C

SVG choropleth (no tiles needed)

Replace the map with a pure SVG Bihar outline — like the analytics scatter plot but for the full state. Districts as SVG paths, no internet required for tiles, fully offline-capable. Works inside the analytics page too.

✅ No tile dependency
✅ Works offline
✅ Matches design system
❌ No street-level zoom
❌ Less familiar as "a map"
My recommendation → A
Fastest path: bundle bihar-districts.geojson in /public, switch tile URL to Stadia (free, no key needed), add crime labels + colour scale. Every map in the dashboard — home preview, hotspots page, analytics scatter — gets fixed in one go.
